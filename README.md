# Estrutura de Dados 1

Este repositório é destinado para as atividades, códigos e estudos referentes à disciplina Estrutura de Dados 1. A disciplina é cursada em 2026/01 na Universidade Tecnológica Federal do Paraná (UTFPR) do campus de Cornélio Procópio.

Principal referência bibliográfica: GOODRICH, Michael T.; TAMASSIA, Roberto. Estruturas de dados & algoritmos em Java. Bookman Editora, 2013.

---
## Conteúdos

### Introdução e sintaxe Java
- Uso de classes, métodos, variáveis e tipos em Java
- Estrutura condicional: `if-else` e `switch-case` 
- Estrutura de repetição: `for`, `while` e `do-while`
- Enumeradores (Enum)
- Modificadores (public, private, protected, final, static)
- Tratamento de excessão (`try-catch` e `throws`)
- Tipos genéricos 

### Índices, nodos e recursão
- Vetor (array) e matriz (array multidimensional)
- TAD lista simplesmente encadeada
- TAD lista duplamente encadeada
- TAD lista circular
- Análise de complexidade das operações
- Algoritmo insertion-sort
- Recursividade

### Pilha (Stack)
- Definição do TAD e operações fundamentais (push e pop)
- Implementação com array (vetor estático)
- Implementação com lista encadeada (nodos, tamanho dinâmico)
- Uso de tipos genéricos e padrão de projeto
- Aplicações da pilha

### Fila (Queue)
- Definição do TAD e operações fundamentais (enqueue e dequeue)
- Implementação com array (vetor estático)
- Implementação com lista encadeada (nodos, tamanho dinâmico)
- Uso de tipos genéricos e padrão de projeto
- Aplicações da fila

### Árvore (Tree)
- Conceitos básicos: raiz, folha, pai, filho, irmão(s), profundidade, altura
- Implementação do TAD Árvore Genérica (com TAD lista de nodos)
- Implementação do TAD Árvore Binária (filhos `left` e `right`)
- Percursos em árvores genéricas: 
    - Prefixado -> `preorder`
    - Posfixado -> `postorder`
- Percursos em árvores binárias:
    - Interfixado -> `inorder`
    - Tour de Euler -> `euler-tour`

---

## Atividades Práticas
- **Lista de contatos**, implementada com TAD lista duplamente encadeada (salva em um arquivo txt)
- **Verificador de balanceamento de parenteses**, uso de pilha para checar expressões com `()`, `[]` e `{}`
- **Avaliação de uma expressão aritmética**, árvore binária própria que avalia uma expressão aritmética e, caso seja válida, constrói uma árvore (calcula o resultado da expressão e desenha a árvore)
